# Carter-Website

Carter's first website — a fundraising initiative for wildlife.

- **`main`** — the files in the repo root serve as the base website template.
- **`example`** — a full example website. It shows what the root files can become: a modern, animated wildlife nonprofit site (WildGuard).

## Example site

The `example` branch contains `index.html`, `style.css`, and `script.js` in the repo root. Just open `index.html` in a browser or serve the folder:

```bash
python3 -m http.server 8000
```
